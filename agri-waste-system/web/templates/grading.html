📸 看图分级教学

根据颜色、霉变、杂质、新鲜度快速判定等级（优/良/中/差），科学选择路线。

快速分级法
  1. 先看红线：严重霉变/腐败/异味 → 直接判为“差”（无害化兜底）。
  2. 再看可追溯：来源不明 → 避免食品/精细提取路线，等级不宜“优”。
  3. 杂质检查：塑料/金属/泥沙多 → 降级，优先走材料/能源/农用方向。
  4. 新鲜度/褐变：存放过久、褐变明显 → 降级并避开高要求提取。
等级对照表
优
新鲜、无霉变、来源明确、杂质少，适配高值化提取。
良
轻度瑕疵可控（轻微霉点/褐变），仍可做材料/农用/部分提取。
中
质量波动明显、杂质偏多或存放偏久，优先选择稳妥路线（材料/能源）。
差
严重霉变腐败/异味/不可追溯，禁入食品与精细提取，走兜底安全处置。
